# Conduit — 0010110

A two-person ritual app built around the sequence **0010110** (value 22).
One person casts a working. The other receives it in a shared pool.

> The sequence is the bridge. The app is the conduit.

## What it does

- **Cast** — set an intention, align the seven bits, iterate, and seal a working
- **Receive** — see workings sealed by anyone on this conduit
- **Grimoire** — your own past workings, saved under your name

Tap **What is this? How do I use it?** inside the app for the steps.
